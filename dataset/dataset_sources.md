## Dataset Preparation Method

The full dataset will not be uploaded to this GitHub repository because it is large. This repository only stores dataset scripts, notes, and small sample images.

The dataset will be filtered based on the selected object classes. Bounding box annotations may be used to crop the target object region to match the one-object-per-scan workflow.

## Dataset Split

- Training set: 70%
- Validation set: 15%
- Testing set: 15%

## Storage

The full dataset will be stored locally or in Google Drive. Only scripts, documentation, and small samples are included in this repository.
